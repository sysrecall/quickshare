
# QuickShare

QuickShare is a lightweight Windows utility that makes sharing files over your **local network** simple and fast.

After installation, you can **right-click any file or group of files and instantly share them** with devices on the same network. QuickShare generates a **QR code and local URL** that others can open in their browser to download the files.

No cloud. No uploads. Just fast local sharing.

---

## Features

-  **Right-click file sharing** directly from Windows Explorer  
-  **Local network only** — files never leave your network (unless port is exposed by you)
-  **Instant share link** generated automatically  
-  **QR code access** for quick downloads on phones and tablets  
-  **Fast transfers** using your LAN speed  
-  **Multiple file support**

---

## Installation

1. Download the latest release from the **Releases** page.
2. Run the installer.
3. Finish setup.

Once installed, **QuickShare integrates into the Windows context menu**.

---

## Usage

1. **Right click** on one or more files in Windows Explorer.
2. Click **QuickShare → Share**.
3. A window will open showing:
   - A **QR code**
   - A **local network URL**

4. On another device connected to the same network:
   - Scan the QR code **or**
   - Open the URL in a browser.

5. Download the shared files.

---


Anyone connected to the same Wi-Fi or LAN can open the link to access the files.

---

## Privacy

QuickShare works **only on your local network**.

- Files are **not uploaded to the internet**
- No third-party servers
- Sharing stops when you close QuickShare

---

## Requirements

- Windows 10 / 11
- Local network connection (Wi-Fi or Ethernet)
- Browser on the receiving device

---

## How It Works

1. Selected files are temporarily hosted by a **local HTTP server**.
2. QuickShare generates a **local IP address link**.
3. The link is encoded into a **QR code**.
4. Devices on the same network can access and download the files.
